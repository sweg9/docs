# dataset documents

Planning documents for the photos and labels used to train and evaluate the detector and to check the VLM prompts. The collection and labeling pipeline is in the [dataset](https://github.com/sweg9/dataset) repo.

| Document | Content |
|---|---|
| [Plan](./PLAN) | Purpose, users, collection method, data use, scope, schedule |
| [PRD](./PRD) | Data requirements, sets and quantities, quality checks, risks |
| [Prompts](./PROMPTS) | Text queries that draft the boxes, and the fixed photo set for prompt checks |
| [Labeling spec](./labeling) | The label format |

The reference is the [proposal](/papers/proposal). Requirement numbers (FR-01 to FR-12) are defined in [Requirements](/product/requirements) and are not redefined here. Numbers in these documents are starting values to be tuned after the first measurements.
