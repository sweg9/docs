# live-demo documents

Planning documents for the front end used with the real camera and actuators. The implementation is in the [live-demo](https://github.com/sweg9/live-demo) repo.

| Document | Content |
|---|---|
| [Plan](./PLAN) | Purpose, users, demo setup, scenarios, scope, schedule |
| [PRD](./PRD) | Screen requirements, behavior rules, what to measure, risks |
| [Prompts](./PROMPTS) | How the demo uses the VLM prompts and handles their answers |

The reference is the [proposal](/papers/proposal). Requirement numbers (FR-01 to FR-12) are defined in [Requirements](/product/requirements) and are not redefined here. Numbers in these documents are starting values to be tuned after the first measurements.
