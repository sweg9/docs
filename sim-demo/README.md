# sim-demo 문서

카메라로 벽 스위치를 인식하고 로봇 팔로 조작해 선제적 홈 루틴에 연결하는 과정을 보여 주는 시뮬레이터 데모의 기획 문서 모음이다. 구현은 [sim-demo](https://github.com/sweg9/sim-demo) 레포에 있다.

| 문서 | 내용 |
|---|---|
| [PLAN.md](PLAN.md) | 기획서: 목적, 대상, 데모 시나리오, 범위, 일정 |
| [PRD.md](PRD.md) | 제품 요구사항: 기능·비기능 요구사항, 지표, 위험 |
| [PROMPTS.md](PROMPTS.md) | 프롬프트 관리: 단계별 프롬프트 목록, 규칙, 템플릿 초안 |

기준 문서는 Phase 2 설계 논문이다. 요구사항 번호(FR, NFR)와 지표 번호(E1~E10), 위험 번호(R1~R7)는 논문과 같게 쓴다. 이 문서의 수치는 모두 목표값(가설)이며 테스트 환경에서 조정한다.
